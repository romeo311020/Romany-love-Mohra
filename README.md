# Mohra

موقع ثابت: شاشة فتح الرسالة (بتشغّل الأغنية) ثم مقدمة قصيرة ثم ٣ صفحات. وكمان لوحة تحكم ليك إنت بس.

## الملفات

- `public/index.html`: صفحة مهرائيل.
- `public/admin.html`: لوحة التحكم (`/admin` بعد النشر).
- `supabase.sql`: جدول الردود (اتنفذ قبل كده).
- `supabase-v2.sql`: جدول الزيارات وصلاحيات القراءة وتنبيه الموبايل.
- `netlify.toml`: إعدادات النشر والأمان.

## الإعدادات

في أول السكريبت داخل `public/index.html`: `FROM_NAME` و`SONG.file` و`SUPABASE_URL` و`SUPABASE_KEY`.
المفتاح publishable مصمم يبقى ظاهر، وأقصى حاجة يعملها إنه يضيف صف.

## تفعيل لوحة التحكم (مرة واحدة، من الموبايل)

1. في Supabase: Authentication ثم Users ثم Add user. اكتب إيميلك وباسورد قوي، وفعّل Auto Confirm.
2. في Authentication ثم Sign In / Providers، قفل **Allow new users to sign up**.
3. افتح SQL Editor ونفّذ الأوامر الموجودة في `supabase-v2.sql` **واحد واحد** (امسح المحرر قبل كل واحد). غيّر `YOUR_EMAIL` في أمرين (٤ و٥) لنفس إيميلك.
4. بعد النشر افتح `/admin` وادخل بالإيميل والباسورد. للتجربة بدون دخول: `/admin#demo`.

## تنبيه على الموبايل

بعد تنفيذ الأمرين ٦ و٧ و٨: نزّل تطبيق **ntfy** واشترك في القناة `mohra-romany-dg7cf5ulfx`. هيجيلك إشعار أول ما ترد.

## اللي بيتسجل

- ردها: الاختيار والرسالة، لما تضغط "ابعتي الرد" بس.
- زيارات: فتحت الرابط، ضغطت وفتحت الرسالة، وصلت لصفحة المشاعر، وصلت لصفحة الرد.
- الاختيار اللي بتجربه على الشاشة من غير ما تبعته مش بيتسجل.
- الصفحة بتقولها ده في أول شاشة.

## النشر

1. ارفع المجلد على مستودع GitHub **Private**.
2. على netlify.com: Add new site ثم Import from Git. الإعدادات بتتاخد من `netlify.toml`.
3. ابعت لها الرابط.

لو الأغنية على رابط خارجي، احتفظ بنسخة منها لأنه ممكن يتمسح.
